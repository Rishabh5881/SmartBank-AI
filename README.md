# SmartBank AI – Backend

Backend API for **SmartBank AI**, a full-stack digital banking platform built with Node.js, Express, Prisma and PostgreSQL.

## 🚀 Tech Stack

* Node.js + Express.js
* PostgreSQL + Prisma ORM
* JWT + Refresh Token Authentication
* bcrypt
* REST APIs

## 📦 Implemented Modules

* Authentication & Authorization
* User & Profile Management
* Accounts & Balances
* Transactions & Transfers
* Loans & Upcoming Payments
* Cards Management
* Notifications
* Dashboard APIs
* Admin APIs

## 🔐 Key Features

* JWT authentication with refresh-token sessions
* Protected routes & role-based access
* Password hashing with bcrypt
* Secure API architecture
* Prisma database integration
* Real-time account and transaction data

## ⚙️ Setup

```bash
npm install
npx prisma generate
npx prisma migrate dev
npm run dev
```

Create a `.env` file with your database and JWT configuration.
